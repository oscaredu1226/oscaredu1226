## 🚀 Featured Projects

### 👁️ Ñawi — Accessible AI Assistant

**2nd Place – TransformaGob National Hackathon 2026**

Ñawi is an accessible conversational assistant designed to help people with visual disabilities independently access government digital services.

The solution combines:

- Artificial Intelligence
- Retrieval-Augmented Generation (RAG)
- Speech Recognition
- Text-to-Speech
- WhatsApp
- TalkBack accessibility
- Spanish and Quechua-oriented interactions

The project addressed an accessibility challenge that could impact more than **4,988 visually impaired citizens in Cusco, Peru**.

Built as a functional prototype by a **3-person multidisciplinary team**.

A full-stack and IoT solution designed to monitor vital signs in real time.

My contributions included:
